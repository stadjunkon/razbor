Работа с копилкой: $ARGUMENTS

Если это новая запись (текст, ссылка, артикул, лайфхак, референс) — положи в `Kopilka/ГГГГ-ММ-ДД-короткое-имя.md`:

```
---
type: kopilka
kind: инсайт | полезное | сервис | товар | инструкция | разбор | приём | референс
topic: тема
date: ГГГГ-ММ-ДД
from: откуда взято
url: ссылка, если есть
sku: артикул, только для товара
price: цена, только для товара
img: кадр или фото, для приёма, референса и товара
---
Текст записи.
```

Поля без значения не пиши. Тип и тему определи сам; если не уверен — спроси одним вопросом. Темы держи короткими и повторяющимися, новую тему заводи, только если ни одна не подходит.

Если я ищу («найди», «покажи всё про…», «сервисы по AI») — найди в `Kopilka/` и покажи списком: тип, тема, текст, ссылка.

Удаление — перенос в `Kopilka/_archive/`.
