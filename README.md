# Разбор

Личная система для Mac: кидаешь видео — получаешь конспект с кадрами, а потом сам выбираешь, что из него забрать в задачи и в копилку.

- Ссылки на YouTube и Loom или свой видеофайл (перетащить в окно).
- Конспект: суть, тезисы, таймлайн с таймкодами и кадры с экрана. Для дизайн-видео есть режим «визуально», где главное — что показано на экране.
- Строки конспекта отправляются в **Задачи** (канбан) или в **Копилку** (инсайты, приёмы, референсы, сервисы).
- Всё хранится обычными Markdown-файлами в папке проекта. Её можно открыть в Obsidian.
- Приложение работает только на твоём компьютере (`localhost`), в интернет не выставляется.

## Как это устроено

```
ссылка или файл
  → yt-dlp скачивает видео и субтитры
  → ffmpeg режет кадры по смене сцены
  → whisper-cpp распознаёт речь, если субтитров нет
  → Claude Code пишет конспект и выбирает кадры
  → страница разбора в браузере → «в задачи» / «в копилку»
```

Конспекты пишет Claude Code под **твоим** аккаунтом Claude. Своего сервера и своих ключей у проекта нет.

## Что нужно

- Mac (Apple Silicon или Intel).
- Подписка Claude (Pro или Max) или API-ключ из [Claude Console](https://platform.claude.com/). Один разбор — это один запуск Claude Code.
- Около 3 ГБ места: модель распознавания речи весит 1.6 ГБ.

## Установка

Все команды вводятся в приложении «Терминал».

**1. Homebrew** — пропусти, если уже стоит (проверка: `brew -v`).

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

В конце установщик покажет две-три команды «Next steps». Выполни их, иначе `brew` не найдётся.

**2. Инструменты**

```bash
brew install git node yt-dlp ffmpeg whisper-cpp
```

**3. Claude Code** ([официальная инструкция](https://code.claude.com/docs/en/setup))

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**4. Модель распознавания речи** (1.6 ГБ). Нужна для своих файлов, Loom и видео без субтитров. Если разбираешь только YouTube с субтитрами, можно поставить позже.

```bash
mkdir -p ~/.local/share/whisper-models && curl -L -o ~/.local/share/whisper-models/ggml-large-v3-turbo.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin
```

**5. Сам проект**

```bash
git clone https://github.com/stadjunkon/razbor.git ~/Documents/Razbor
```

**6. Вход в Claude.** Открой папку `~/Documents/Razbor` в Finder и дважды щёлкни **«Войти в Claude.command»**. Откроется браузер — войди в свой аккаунт Claude. Это нужно один раз.

**7. Запуск.** Дважды щёлкни **«Открыть Разбор.command»**. Откроется http://localhost:3170. Окно Терминала не закрывай, пока пользуешься приложением.

Если macOS пишет, что файл нельзя открыть: щёлкни по нему правой кнопкой → «Открыть» → «Открыть». Если Терминал просит доступ к папке «Документы» — разреши.

## Как пользоваться

1. Вставь ссылку в поле — разбор начнётся сам. Свой видеофайл перетащи в окно или нажми «Файл с компьютера».
2. В «Настройках разбора» можно выбрать:
   - **глубину:** бегло, обычно, подробно, визуально;
   - **фокус** — на что обратить внимание;
   - **подборку** — разборы одного курса или темы окажутся рядом.
3. Разбор занимает несколько минут. Пока он идёт, можно кидать следующие ссылки: они встанут в очередь.
4. Открой готовый разбор и отбери строки справа. Для каждой выбери, куда она идёт: в задачи или в копилку (с типом записи).
5. Вкладки **Задачи** и **Копилка** — всё, что ты забрал.

То же можно делать без приложения, прямо в Claude Code:

```bash
cd ~/Documents/Razbor && claude
```

| Команда | Что делает |
|---|---|
| `/razbor ссылка визуально` | Разбор (глубина: бегло, обычно, подробно, визуально; можно добавить `фокус: ...`) |
| `/zabrat т2, т5 в копилку; п1 в задачи` | Забрать пункты из последнего разбора |
| `/zadachi` | Задачи: «добавь: …», «сделал 3», «3 в сейчас» |
| `/kopilka` | Положить запись в копилку или найти в ней |

## Где что лежит

| Путь | Что там |
|---|---|
| `Razbor/ГГГГ-ММ-ДД-имя/` | `razbor.md` (конспект), `page.html` (страница), `img/` (кадры) |
| `Kopilka/` | По файлу на запись |
| `tasks.md` | Список задач по разделам: Входящие, Сейчас, Дальше, Когда-нибудь, Сделано |
| `Tasks/` | Подробности задач: описание, подшаги, комментарии |
| `tools/` | Сам инструмент: `razbor.mjs` (добыча видео и сборка страниц), `server.mjs` и `app.html` (приложение) |
| `.claude/commands/` | Команды для Claude Code |
| `CLAUDE.md` | Правила для Claude в этой папке. Их можно менять под себя |

Ничего не удаляется насовсем: «удалить» переносит файл в `_archive/` той же папки. Перед каждым изменением `tasks.md` сохраняется копия в `.backups/`.

## Если что-то не работает

- **«Claude не подключён».** Ещё раз запусти «Войти в Claude.command» и доведи вход до конца.
- **YouTube не отдаёт видео** («Sign in to confirm you're not a bot», ошибка 429). Подожди полчаса и обнови yt-dlp: `brew upgrade yt-dlp`. YouTube часто меняется, и yt-dlp догоняет его обновлениями.
- **«нет модели распознавания речи».** Выполни шаг 4 установки.
- **Порт 3170 занят.** Приложение уже запущено в другом окне Терминала — просто открой http://localhost:3170.
- **Разбор упал.** Нажми на карточке «Повторить». Подробности ошибки — в окне Терминала, где запущено приложение.

## Обновление

```bash
cd ~/Documents/Razbor && git pull
```

Твои разборы, копилка и задачи в git не попадают (см. `.gitignore`), поэтому обновление их не тронет.

## Важно про права

- Скачивай и разбирай только то, на что у тебя есть право. Условия YouTube запрещают скачивать видео без разрешения YouTube или правообладателя. Отвечаешь за это ты, как и при любом использовании yt-dlp.
- Конспекты — для себя. Не выкладывай публично конспекты и кадры платных курсов.
- Закрытые платформы курсов (Kinescope и подобные) не поддерживаются, и защиту обходить не нужно. Если нужен файл урока, попроси его у автора и перетащи в окно.
